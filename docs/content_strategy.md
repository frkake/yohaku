## 2. StillMotion ページ構成とコピー戦略

### 2-1. ヒーローセクション

**構成要素:**
- アプリアイコン（山 + 再生ボタンのモチーフ）
- キャッチコピー
- サブキャッチ
- App Store ダウンロードバッジ
- ヒーロービジュアル（アプリスクリーンショットのモックアップ）

**日本語:**
```
画像も動画も、区別なく。

写真、RAW、MKV、WebM――20種類以上のフォーマットに対応。
6つのメディアソースをひとつのアプリで、シームレスに。

[App Store でダウンロード]
```

**English:**
```
Images and videos, without boundaries.

Photos, RAW, MKV, WebM -- 20+ formats supported.
6 media sources in one app, seamlessly.

[Download on the App Store]
```

**コピー戦略:**
- 「区別なく」がStillMotionの核心的価値。画像/動画の壁を取り払うという一点に絞る
- フォーマット数・ソース数を具体的に提示し、機能の幅広さを即座に伝える
- 技術用語（RAW, MKV）を敢えて入れることで、対象ユーザー（メディア愛好家）に「自分向けだ」と認識させる

### 2-2. 機能紹介セクション

3〜4つの主要機能を順に紹介する。各機能は「見出し + 1〜2行の説明 + ビジュアル」で構成。

#### Feature 1: シームレスなスライドショー

**日本語:**
```
画像と動画を混ぜて、連続再生。

スライドショーに画像も動画も区別なく並べられる。
クロスフェード、シャッフル、再生間隔のカスタマイズも自由自在。
再生中にリアルタイムで設定変更。止める必要はありません。
```

**English:**
```
Mix images and videos. Play them together.

Line up photos and videos in a single slideshow.
Crossfade, shuffle, custom intervals -- all adjustable in real time,
without stopping playback.
```

**コピー戦略:** "止める必要はありません" -- リアルタイム設定変更という差別化ポイントを自然に伝える

---

#### Feature 2: タイル表示（有料）

**日本語:**
```
最大30枚を、1画面に。

タイル表示なら、画像も動画も一度に並べて確認できる。
メディア数に応じて自動レイアウト。ドラッグで並び替え、
ピンチズームで拡大。動画はインラインで再生。
```

**English:**
```
Up to 30 items, one screen.

Tile view lets you compare images and videos side by side.
Auto-layout adapts to your media count. Drag to rearrange,
pinch to zoom. Videos play inline.
```

**コピー戦略:** 数字（30枚）で具体性を出す。他のメディアビューアにない独自機能をアピール

#### Feature 3: デュアルエンジン動画再生

**日本語:**

MP4やMOVはもちろん、MKV、WebM、FLV、WMV、AVIまで。

**English:**

No format left behind.

Dual engines -- AVPlayer and VLCKit -- switch automatically.
MP4, MOV, MKV, WebM, FLV, WMV, AVI and more.
Files your default app couldn't play? StillMotion can.

**コピー戦略:** 「再生できない→もうない」という課題解決型のメッセージ。ユーザーの不満に直接応える

## 3. ダウンロードページ（ローカルサーバー）

### ページ構成

#### 3-1. ヘッダー

**日本語:**
```
StillMotion Local Server

PCのメディアを、手元のデバイスで。
LAN経由でPC上の写真・動画をStillMotionアプリから直接閲覧。
インターネット接続不要。QRコードで簡単ペアリング。
```

**English:**
```
StillMotion Local Server

Your PC media, on your device.
Browse photos and videos on your PC directly from the StillMotion app, over LAN.
No internet required. Pair with a QR code.
```

#### 3-2. 特徴リスト

- **ゼロ設定**: ダウンロードして起動するだけ。設定は不要。
- **QRコードペアリング**: アプリからQRコードをスキャンするだけで接続完了。
- **サムネイル生成**: サーバー側でサムネイルを自動生成し、転送量を削減。
- **Web管理画面**: ブラウザベースの管理UIでメディアルートを設定。
- **セキュリティ**: LAN内のみ通信。トークンベースの認証。

#### 3-3. ダウンロードセクション

バイナリは **GitHub Releases** から配布する。ダウンロードボタンは GitHub Releases のアセット URL にリンクする。

| プラットフォーム | ファイル名 | サイズ | 補足 |
|---|---|---|---|
| macOS (Apple Silicon) | `StillMotion-Server-1.1.dmg` | 5.9MB | 推奨。DMGインストーラー |
| macOS (Apple Silicon) | `stillmotion-server-darwin-arm64` | 6.7MB | CLI バイナリ |
| macOS (Intel) | `stillmotion-server-darwin-amd64` | 7.1MB | CLI バイナリ |
| Linux (x86_64) | `stillmotion-server-linux-amd64` | 6.9MB | CLI バイナリ |
| Linux (ARM64) | `stillmotion-server-linux-arm64` | 6.6MB | Raspberry Pi 等 |
| Windows (x86_64) | `stillmotion-server-windows-amd64.exe` | 7.1MB | ダブルクリックで起動 |
| Windows (ARM64) | `stillmotion-server-windows-arm64.exe` | 6.6MB | ダブルクリックで起動 |

#### 3-4. セットアップガイド（簡易版）

```
1. ダウンロードして起動
2. ブラウザで管理画面が自動的に開く
3. メディアフォルダを設定
4. 共有を有効化
5. StillMotionアプリからQRコードをスキャンして接続
```

#### 3-5. ffmpeg について

**日本語:**
```
動画のサムネイル生成には ffmpeg が必要です（オプション）。
ffmpeg がない場合でも、アプリ側でサムネイルが生成されます。
```

## 5. 多言語コンテンツ方針

### 5-1. 言語優先度

**日本語を第一言語（プライマリ）とする。**

**理由:**
1. 開発者が日本語ネイティブであり、ニュアンスの精度が高い
2. 日本市場では品質の高い日本語コピーが信頼感に直結する
3. App Store の主要ターゲットが日本市場から開始
4. 個人ブログ (frkake.com) も日本語で運営しており、ブランドの一貫性

### 5-2. 多言語対応方針

| 項目 | 方針 |
|---|---|
| URL構造 | Hugoの多言語機能を使用。`/ja/` (デフォルト) / `/en/` |
| デフォルト言語 | 日本語 (`ja`) |
| 英語コンテンツ | 日本語からの翻訳ではなく、英語ネイティブに自然なコピーとして別途作成 |
| hreflang | `<link rel="alternate" hreflang="ja" ...>` / `<link rel="alternate" hreflang="en" ...>` を設定 |
| 言語切替UI | ヘッダーまたはフッターに言語切替リンク（JA / EN） |

### 5-3. コンテンツローカリゼーション方針

日本語と英語で単純な逐語翻訳を避け、各言語で自然なコピーライティングを行う。

**日本語コピーの特徴:**
- 体言止め・短文で余韻を残すスタイル（「画像も動画も、ひとつに。」）
- 具体的な数字で信頼感を出す
- 「〜できる」よりも「〜を。」で完結させるリズム

**英語コピーの特徴:**
- 直接的で力強い表現（"No format left behind."）
- 動詞で始まるアクション指向（"Mix images and videos."）
- 短いセンテンスの連続でリズムを作る

**翻訳で特に注意するポイント:**
- アプリ名「StillMotion」はそのまま使用（翻訳しない）
- 技術用語（RAW, MKV, VLCKit等）はそのまま使用
- 価格表示はロケールに合わせる（¥800 / $4.99）
- App Storeリンクは地域別URLを使用

## 6. コンテンツトーン & ボイスガイドライン

### ブランドボイス

| 属性 | 説明 |
|---|---|
| **明快** | 回りくどい説明を避け、短く的確に伝える |
| **誠実** | 誇張しない。できることを正直に伝える |
| **プロフェッショナル** | 技術に詳しいユーザーに対して、知識のある語り口 |
| **控えめ** | 過度な装飾を避け、機能で語る（Less is More の精神） |

### やること / やらないこと

| やること | やらないこと |
|---|---|
| 具体的な数字を使う（6ソース、20+フォーマット） | 「最高の」「革命的な」など誇大表現 |
| ユーザーの課題に寄り添う（「再生できなかったファイルも」） | 競合を名指しで批判する |
| 買い切り・広告なしを強調する | サブスクや広告モデルを否定する |
| 短い文で区切る | 長文の説明パラグラフ |
| 技術用語を適切に使う（ターゲットが理解できる前提） | 専門用語を過度に使って排他的にする |
