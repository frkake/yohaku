## はじめに

本プライバシーポリシーは、Takumi Iida が開発したアプリケーション「StillMotion」（以下「本アプリ」）におけるデータの取り扱いについて説明するものです。本ポリシーは、本アプリが提供するすべての機能およびサービスに適用されます。

## 収集する情報

本アプリは、ユーザーの個人情報を一切収集しません。

Apple が提供する標準的な分析機能（App Analytics）を通じて、匿名化された利用統計情報を取得する場合があります。これにはアプリの使用状況やクラッシュレポートが含まれます。本アプリは、他のアプリやウェブサイトにわたるユーザーの追跡を行いません（`NSPrivacyTracking = false`）。

## 第三者サービスとの連携

本アプリは、以下の第三者サービスとのオプション連携機能を提供します。すべての連携は読み取り専用であり、本アプリ内でのメディアの閲覧・表示のみを目的としています。以下に記載された一部の連携機能は、現在のリリースではまだ利用できない場合があります。

### Google Drive

- **スコープ:** `drive.readonly`（読み取り専用アクセス）
- **用途:** ファイル・フォルダの一覧表示、メディアのダウンロード・閲覧
- **API:** Google Drive API v3
- **認証方式:** OAuth 2.0 + PKCE (SHA-256)
- 本アプリは、Google Drive 上のファイルの変更・削除・作成を一切行いません。

### Google Photos

- **スコープ:** `photospicker.mediaitems.readonly`（読み取り専用アクセス）
- **用途:** ユーザーが選択した写真の閲覧
- **API:** Google Photos Picker API v1
- **認証方式:** OAuth 2.0 + PKCE (SHA-256)
- 本アプリは、Google Photos 上の写真の変更・削除・アップロードを一切行いません。

### Dropbox

- **アクセス:** 読み取り専用（フォルダ一覧、一時ダウンロードリンク取得、サムネイル取得）
- **API:** Dropbox API v2（`list_folder`、`get_temporary_link`、`get_thumbnail_v2`）
- **認証方式:** OAuth 2.0 + PKCE (SHA-256)
- 本アプリは、Dropbox 上のコンテンツの書き込み・削除・変更を一切行いません。

### SSH/SFTP

- ユーザーが設定したサーバーへの読み取り専用接続
- 認証情報は Apple Keychain に暗号化して保存されます

### ローカルサーバー

- ユーザーのローカルネットワーク（LAN）内でのみ動作します
- インターネットを通じたデータの送受信は行いません

### 写真アプリ・ファイルアプリ

- OS 標準のアクセスメカニズムを介してアクセスします

## データの利用目的

- 第三者サービスを通じてアクセスしたデータは、本アプリ内でのメディアの閲覧・表示機能の提供のみに使用します。
- 広告・マーケティング・分析目的でのデータ利用は一切行いません。
- 第三者へのデータ提供は一切行いません。

## データの保存とセキュリティ

- **OAuth トークン:** Apple Keychain に暗号化して保存
- **メディアキャッシュ:** デバイスのキャッシュディレクトリに保存（TTL: 24時間、サムネイル: 3.5時間）
- **設定情報:** UserDefaults にローカル保存
- **開発者のサーバーへのデータ送信は一切ありません。**
- すべての API 通信は HTTPS により暗号化されます。

## データの保持と削除

- キャッシュデータは TTL 経過後に自動的に削除され、LRU 方式によりサイズが制限されます。
- 本アプリ内でキャッシュを手動でクリアすることができます。
- 各サービスからログアウトすると、Keychain からトークンが即時削除されます。
- 本アプリを削除すると、関連するすべてのデータがデバイスから削除されます。
- Google アカウントへのアクセスは、[https://myaccount.google.com/permissions](https://myaccount.google.com/permissions) からいつでも取り消すことができます。
- Dropbox アカウントへのアクセスは、[https://www.dropbox.com/account/connected_apps](https://www.dropbox.com/account/connected_apps) からいつでも取り消すことができます。

## Google API サービス — 限定的使用に関する開示

StillMotion による Google API から受け取った情報の使用および他のアプリへの転送は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（限定的使用の要件を含む）に準拠します。

具体的に、本アプリは以下の要件を遵守します：

1. **Google API データは、メディアの閲覧・表示機能の提供のみに使用します。** これは、本ポリシーに記載された本アプリの中核機能です。
2. **Google API データを第三者に転送しません。** ただし、アプリの機能提供または改善に必要な場合、ユーザーの同意がある場合、セキュリティ上の目的がある場合、または法令遵守に必要な場合を除きます。
3. **Google API データを広告目的で使用しません。** 本アプリは広告を配信せず、Google API データが広告の配信、ターゲティング、パーソナライズに使用されることはありません。
4. **ユーザーの明示的な同意がある場合、セキュリティ上の目的がある場合、法令遵守に必要な場合、またはデータが集約・匿名化されて内部運用に使用される場合を除き、人が Google API データを閲覧することはありません。**

## データの共有

- 当社は、ユーザーのデータを第三者と一切共有しません。
- 本アプリには、広告 SDK や第三者分析 SDK は組み込まれていません。
